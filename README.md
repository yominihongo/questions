# YomiNihongo — JLPT Questions

This repository stores JSON files created for **YomiNihongo**.

## About

YomiNihongo is a Japanese learning project focused on helping students prepare for the JLPT through practice exercises and detailed explanations.

## Purpose

The JSON files are used to dynamically load JLPT practice questions and explanations on the YomiNihongo website.

The repository serves as a public content storage resource and is not intended as a standalone application.

## Disclaimer

The practice questions are independently created for educational purposes and are not official JLPT examination materials.

YomiNihongo is not affiliated with or endorsed by the Japan Foundation or Japan Educational Exchanges and Services (JEES).
